Sport Sitters

A live iPhone and Android marketplace where parents book NCAA Division I college athletes for childcare, tutoring and supervised sessions.

CIC Launchpad

A free learning website for Coding in Color, a Phoenix nonprofit that teaches computer science to Arizona high schoolers whose schools don't offer it. It moves their classes from slide decks to one link.

What I built

  • The teacher dashboard logic, including student status, concept mastery and the learning-gain math.
  • The design, an in-browser code editor and drag-and-drop lesson reordering.
  • A read API protected by a key. I kept shipping improvements after judging.
More about this project
  • Students join with a class code and a personal code. No email or password.
  • Real Python runs right in the browser.
  • A missed lesson turns into a catch-up of about 15 minutes.
  • The teacher dashboard leads with one plain sentence, like "1 student needs help. 3 are behind. 8 are doing fine."
  • Before and after quizzes measure how much students learned.
  • It targets WCAG 2.2 AA accessibility and has more than 150 automated tests.

Team. No 1 Left Behind, with Shrey Bishnoi and Maulik Kalpesh Jadav. Our win came with the Founding Engineer Prize to keep building with Coding in Color.

HackUTD · Nov 2026

Pit Pal

A low-cost AI racing coach for the Assetto Corsa racing simulator. You steer with an iPhone and drive with pedals we built on an Arduino. NVIDIA's Nemotron AI model writes one tip for each corner, and the car rewinds so you can try that corner again.

What I built

  • Rev, the talking on-screen mascot that coaches the driver.
  • The crash-and-retry rewind flow.
  • A session history viewer with a lap chart and CSV export.
  • Pedal calibration with a safe fallback if a sensor stops sending data.
  • Protection for the local dashboard against cross-site request attacks.

Team. Team Obsidian, with Keven Diaz, Kevin Jiang and Will Yang.

  • Python
  • NVIDIA Nemotron
  • Arduino
  • Assetto Corsa telemetry

A free web app where parents practice 12 hard conversations with a child character who reacts to every answer. There is no sign-up, and nothing a parent types leaves their device.
